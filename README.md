# ❄ Юки — ИИ-ассистент с аниме-девушкой для Android

Беловолосая тихоня-дандэрэ живёт поверх экрана, гуляет по нему, моргает, меняет эмоции,
слушает голосом и делает на телефоне то, что попросишь. Мозг — Claude.

## Что умеет (версия 0.1)
- Сидит поверх всех приложений, сама гуляет, её можно таскать пальцем.
- Эмоции: спокойная, радостная, смущённая, задумчивая, удивлённая, грустная, сонная, недовольная, слушает.
- Голосовая активация по имени: «Юки, поставь будильник на семь».
- Отвечает голосом (встроенный синтез речи, тон повыше) + облачко с текстом.
- Управляет телефоном: открывает приложения, читает экран, нажимает, листает, печатает,
  смотрит скриншоты, звонит, открывает СМС, будильники, таймеры, музыка, громкость, фонарик, поиск.
- Перед отправкой сообщений, звонками, покупками и удалением — переспрашивает.
- Приватные приложения (банки и т.п.) не читает — список меняется в настройках.

## Как собрать APK с телефона
1. Залей эти файлы в репозиторий на GitHub (ветка `main`).
2. GitHub сам запустит сборку: вкладка **Actions** → «Собрать APK» (≈5 минут).
3. Готовый файл: вкладка **Releases** → «Юки — свежая сборка» → **Yuki.apk**.
4. Открой на телефоне, разреши установку из этого источника.

## Первый запуск
1. **Поверх других окон** → разрешить.
2. **Микрофон, звонки, контакты** → разрешить.
3. **Спецвозможности** → «Юки — управление телефоном» → включить.
   Если серое: Сведения о приложении → ⋮ → «Разрешить ограниченные настройки».
4. Вставить **ключ API** Claude (console.anthropic.com → API Keys). Нужен пополненный баланс.
5. **▶ Запустить Юки**.

Тап по Юки — сразу слушает. Долгое нажатие — замолкает и отменяет дело.

## Важно знать
- Всё, что Юки «видит» на экране, отправляется в Claude API для обработки.
- Режим ожидания имени использует распознавание речи Google: тратит батарею и интернет.
- Ключ API хранится только на телефоне, в репозиторий не попадает.

## Планы
- Живая Live2D-модель вместо векторной.
- Голос ElevenLabs (аниме-тембр).
- Офлайн-активация по имени (Porcupine / Vosk) — экономнее и без писка.
